# Installation & Local Setup

## Prerequisites
- Node.js >= 18.18.0 (Node 24 tested)
- npm >= 9.0.0

## Quick Start
```bash
cd global-media-tools
npm install
npm run dev
```

Visit: `http://localhost:3000`

## Build & Test Commands
- `npm run build`: Production Next.js build
- `npm run type-check`: Full TypeScript validation (`tsc --noEmit`)
- `npm run lint`: Next.js ESLint verification
- `npm test`: Node.js built-in automated test suite
